# FLUX 风格提示词模板

## 基础结构
```
[艺术风格], [渲染风格], [色彩风格], [材质风格], [参考艺术家], [画质参数]
```

## 示例（英文）
```
anime style, digital art, vibrant colors, soft lighting, studio ghibli, best quality, masterpiece
```

## 示例（中文参考）
```
动漫风格，数字艺术，鲜艳色彩，柔和光线，吉卜力工作室风格，最佳质量，杰作
```

## 参数说明
1. 艺术风格：整体艺术表现形式
2. 渲染风格：具体的渲染技术
3. 色彩风格：色彩搭配和氛围
4. 材质风格：材质表现特点
5. 参考艺术家：艺术家或作品风格
6. 画质参数：quality相关参数

## 常用风格标签对照表
### 基础风格
- 写实风格：photorealistic, hyperrealistic - 照片级写实，超写实
- 动漫风格：anime style, manga style - 日本动漫，漫画风格
- 插画风格：illustration, concept art - 插画，概念艺术
- 油画风格：oil painting, impressionist - 油画，印象派
- 水彩风格：watercolor, traditional media - 水彩，传统媒介
- 像素风格：pixel art, 8-bit style - 像素艺术，8位风格
- 赛博朋克：cyberpunk, sci-fi - 赛博朋克，科幻
- 奇幻风格：fantasy, magical - 奇幻，魔法

### 渲染风格
- digital painting - 数字绘画
- 3D rendering - 3D渲染
- hand drawn - 手绘风格
- vector art - 矢量艺术
- sketch - 素描风格
- comic style - 漫画风格

### 色彩风格
- vibrant - 鲜艳的
- muted - 柔和的
- monochrome - 单色的
- pastel - 粉彩的
- dark - 暗色调
- bright - 明亮的

### 材质风格
- metallic - 金属质感
- glossy - 光泽的
- matte - 哑光的
- transparent - 透明的
- rough - 粗糙的
- smooth - 光滑的

## 注意事项
- 风格要统一
- 避免风格冲突
- 合理使用参考
- 注意版权问题
- 英文提示词效果通常优于中文
