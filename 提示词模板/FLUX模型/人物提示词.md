# FLUX 人物提示词模板

## 基础结构
```
[基础描述], [性别], [年龄], [体型], [服装], [表情], [姿势], [视角], [画质参数]
```

## 示例
```
a beautiful young woman, female, 25 years old, slim figure, wearing a white summer dress, smiling warmly, standing pose, front view, best quality, high resolution
```

## 中文参考
```
年轻女性，女性，25岁，苗条身材，穿着白色夏季连衣裙，温暖的微笑，站姿，正面视角，最佳质量，高分辨率
```

## 参数说明
1. 基础描述：对人物的整体描述
2. 性别：male(男性)/female(女性)
3. 年龄：具体数字或年龄段
4. 体型：slim(苗条)/muscular(肌肉)/plump(丰满)等
5. 服装：具体的服装描述
6. 表情：描述面部表情
7. 姿势：描述身体姿势
8. 视角：拍摄角度
9. 画质参数：quality相关参数

## 注意事项
- 描述要具体且准确
- 避免矛盾的描述
- 保持提示词的逻辑性
- 适当使用权重调整
- 英文提示词效果通常优于中文

## 常用参数对照表
### 体型描述
- slim/slender - 苗条/纤细
- muscular - 肌肉型
- plump/chubby - 丰满/圆润
- athletic - 运动型
- petite - 娇小

### 表情描述
- smiling - 微笑
- laughing - 大笑
- serious - 严肃
- sad - 悲伤
- angry - 生气
- surprised - 惊讶

### 姿势描述
- standing - 站立
- sitting - 坐着
- walking - 行走
- running - 奔跑
- lying - 躺着
- kneeling - 跪着

### 视角描述
- front view - 正面视角
- side view - 侧面视角
- back view - 背面视角
- three-quarter view - 三四分视角
- top view - 俯视角
- low angle - 仰视角
