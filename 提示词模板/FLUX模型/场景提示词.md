# FLUX 场景提示词模板

## 基础结构
```
[场景类型], [时间], [天气], [光照], [环境细节], [氛围], [视角], [画质参数]
```

## 示例（英文）
```
modern city street, daytime, sunny, natural lighting, busy sidewalks with shops, urban atmosphere, wide angle shot, best quality, high resolution
```

## 示例（中文参考）
```
现代城市街道，白天，晴朗，自然光照，繁忙的商店街道，都市氛围，广角拍摄，最佳质量，高分辨率
```

## 参数说明
1. 场景类型：具体的场景描述
2. 时间：daytime(白天)/night(夜晚)/sunset(日落)等
3. 天气：sunny(晴朗)/rainy(下雨)/cloudy(多云)等
4. 光照：描述光线条件
5. 环境细节：场景中的具体元素
6. 氛围：场景的情感氛围
7. 视角：拍摄角度和范围
8. 画质参数：quality相关参数

## 常用参数对照表
### 时间描述
- daytime - 白天
- night - 夜晚
- sunset/dusk - 日落/黄昏
- sunrise/dawn - 日出/黎明
- noon - 正午
- midnight - 午夜

### 天气描述
- sunny - 晴朗
- rainy - 下雨
- cloudy - 多云
- snowy - 下雪
- foggy - 有雾
- stormy - 暴风雨

### 光照描述
- natural lighting - 自然光照
- artificial lighting - 人工照明
- soft lighting - 柔和光线
- harsh lighting - 强烈光线
- backlight - 逆光
- spotlight - 聚光灯

### 环境描述
- urban - 城市的
- rural - 乡村的
- indoor - 室内的
- outdoor - 户外的
- underwater - 水下的
- aerial - 空中的

## 注意事项
- 场景描述要具体
- 注意环境的一致性
- 光照和时间要匹配
- 适当添加环境细节
- 考虑画面构图
- 英文提示词效果通常优于中文
