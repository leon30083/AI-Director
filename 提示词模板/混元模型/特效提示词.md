# 混元视频 特效提示词模板

## 基础结构
```
[特效类型], [特效强度], [特效范围], [特效时间], [特效细节], [画质参数]
```

## 示例（英文）
```
particle effect, medium intensity, full screen, 2 seconds duration, glowing particles floating upward, high quality
```

## 示例（中文参考）
```
粒子特效，中等强度，全屏范围，2秒持续时间，向上漂浮的发光粒子，高质量
```

## 常用特效类型对照表
1. 粒子特效
   - particles (粒子) - 基础粒子
   - sparkles (火花) - 闪烁效果
   - dust (灰尘) - 漂浮灰尘
   - snow (雪花) - 飘雪效果
   - rain (雨滴) - 下雨效果
   - fire (火焰) - 火焰效果

2. 光效
   - lens flare (镜头光晕) - 镜头耀斑
   - glow (发光) - 物体发光
   - bloom (泛光) - 光芒四射
   - light rays (光线) - 光束效果
   - god rays (神光) - 体积光
   - rainbow (彩虹) - 彩虹效果

3. 环境特效
   - fog (雾气) - 雾气效果
   - mist (薄雾) - 轻雾效果
   - smoke (烟雾) - 烟雾效果
   - clouds (云彩) - 云层效果
   - lightning (闪电) - 闪电效果
   - aurora (极光) - 极光效果

4. 视觉效果
   - blur (模糊) - 模糊效果
   - glitch (故障) - 画面故障
   - distortion (扭曲) - 画面扭曲
   - chromatic aberration (色差) - 色彩偏移
   - vignette (暗角) - 边缘暗化
   - film grain (胶片颗粒) - 胶片质感

## 参数说明
1. 特效类型：具体的特效种类
2. 特效强度：效果的强弱程度
3. 特效范围：效果的作用范围
4. 特效时间：效果的持续时间
5. 特效细节：具体的效果描述
6. 画质参数：quality相关参数

## 强度参数对照表
- subtle - 微弱的
- light - 轻微的
- medium - 中等的
- strong - 强烈的
- intense - 剧烈的

## 范围参数对照表
- local - 局部的
- partial - 部分的
- full screen - 全屏的
- centered - 居中的
- peripheral - 边缘的

## 注意事项
- 特效要自然
- 不要过度使用
- 注意整体协调
- 避免干扰主体
- 控制特效强度
- 英文提示词效果通常优于中文
