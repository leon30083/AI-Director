# 混元视频 运镜提示词模板

## 基础结构
```
[运动类型], [运动方向], [运动速度], [运动幅度], [运动节奏], [画质参数]
```

## 示例（英文）
```
camera pan, left to right, slow speed, medium range, smooth motion, high quality
```

## 示例（中文参考）
```
相机平移，从左到右，慢速，中等范围，平滑运动，高质量
```

## 常用运动类型对照表
1. 相机运动
   - pan (平移) - 相机水平移动
   - tilt (俯仰) - 相机垂直移动
   - dolly (推拉) - 相机前后移动
   - truck (横移) - 相机侧向移动
   - pedestal (升降) - 相机上下移动
   - orbit (环绕) - 相机环绕运动

2. 镜头变化
   - zoom in (拉近) - 镜头拉近
   - zoom out (拉远) - 镜头拉远
   - rack focus (焦点转移) - 焦点变换
   - dutch angle (倾斜角度) - 画面倾斜

3. 跟随运动
   - follow shot (跟随镜头) - 跟随拍摄
   - tracking shot (轨道跟拍) - 轨道运动
   - steady cam (稳定跟拍) - 稳定器拍摄

## 参数说明
1. 运动类型：具体的运动方式
2. 运动方向：移动的方向
3. 运动速度：动作的速度
4. 运动幅度：动作的范围
5. 运动节奏：动作的节奏感
6. 画质参数：quality相关参数

## 速度参数对照表
- very slow - 非常慢
- slow - 慢速
- moderate - 中等速度
- fast - 快速
- very fast - 非常快

## 幅度参数对照表
- subtle - 微小的
- small - 小幅度
- medium - 中等幅度
- large - 大幅度
- extreme - 极大幅度

## 节奏参数对照表
- smooth - 平滑的
- steady - 稳定的
- dynamic - 动态的
- rhythmic - 有节奏的
- fluid - 流畅的

## 注意事项
- 运动要流畅
- 速度要合适
- 避免过度晃动
- 保持画面稳定
- 注意运动连续性
- 英文提示词效果通常优于中文
