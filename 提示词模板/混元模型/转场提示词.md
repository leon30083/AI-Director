# 混元视频 转场提示词模板

## 基础结构
```
[转场类型], [转场方向], [转场速度], [转场效果], [画质参数]
```

## 示例（英文）
```
fade transition, left to right, moderate speed, smooth blend, high quality
```

## 示例（中文参考）
```
淡入淡出转场，从左到右，中等速度，平滑混合，高质量
```

## 常用转场类型对照表
1. 淡入淡出 (Fade)
   - fade in - 淡入
   - fade out - 淡出
   - cross fade - 交叉淡入淡出

2. 推移 (Push)
   - push left - 向左推移
   - push right - 向右推移
   - push up - 向上推移
   - push down - 向下推移

3. 溶解 (Dissolve)
   - dissolve - 溶解
   - smooth dissolve - 平滑溶解
   - pixel dissolve - 像素溶解

4. 旋转 (Rotate)
   - rotate clockwise - 顺时针旋转
   - rotate counterclockwise - 逆时针旋转
   - spiral rotate - 螺旋旋转

5. 缩放 (Zoom)
   - zoom in - 放大
   - zoom out - 缩小
   - zoom blur - 缩放模糊

## 参数说明
1. 转场类型：具体的转场方式
2. 转场方向：运动的方向
3. 转场速度：动画的速度
4. 转场效果：特殊效果描述
5. 画质参数：quality相关参数

## 速度参数对照表
- very slow - 非常慢
- slow - 慢速
- moderate - 中等速度
- fast - 快速
- very fast - 非常快

## 效果参数对照表
- smooth - 平滑的
- sharp - 锐利的
- soft - 柔和的
- hard - 硬切的
- blurred - 模糊的
- clear - 清晰的

## 注意事项
- 转场要流畅自然
- 速度要适中
- 避免晕眩效果
- 保持视觉连续性
- 英文提示词效果通常优于中文
